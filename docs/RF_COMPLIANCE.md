# РФ-Комплаенс — чек-лист внедрённого

| Требование | Где реализовано |
| --- | --- |
| Политика конфиденциальности (ФЗ-152) | Страница `/privacy`, `src/pages/Privacy.tsx` |
| Согласие под кнопкой записи | Галочка в `BookingModal` перед «Подтвердить запись», ссылка на `/privacy`; сервер возвращает 400 без `consent=true` |
| Пользовательское соглашение | Страница `/terms-of-use`, ссылка в Footer и drawer-меню |
| Реквизиты ИП жирным внизу Footer | `LEGAL.ipName · ИНН … · ОГРНИП …` в `src/components/Footer.tsx` |
| Cookie-баннер «Принять все» / «Настройки» | `src/components/CookieBanner.tsx`, consent в `localStorage`, настройки категорий |
| Цены всегда доступны | Полный прайс-лист на главной (`Services`), `GET /api/services` |
| Возрастная маркировка 16+ | Hero-meta, прайс (Hard Gel/донаращивание), Footer |
| «Имеются противопоказания» | Плашки у сложных процедур в прайсе, Footer, документах |
| Отказ от ответственности «не оферта» | Footer + Пользовательское соглашение |

## Что добавить перед запуском

- **ИНН / ОГРНИП / ФИО**: заменить значения-заглушки в `client/src/lib/site.ts`
  (блок `LEGAL`) и `server/src/data/site.ts` при необходимости.
- **Согласие**: для соответствия практике Роскомнадзора рекомендуется
  сохранять отметку согласия с датой и содержимым формы (в `bookings.json`
  уже хранится `consent`-флаг и время `createdAt`).
- **Правовая проверка текстов**: передать `src/pages/Privacy.tsx` и
  `src/pages/TermsOfUse.tsx` юристу перед публикацией.
- **Соцсети**: VK-ссылка — заглушка, заменить на реальную группу.
- **Instagram**: стоит пометка о возможных ограничениях доступа на территории РФ.
